# Skill #10 — Decision Support

## IE 591 — AI Portfolio Optimization

Skill #10 provides the decision intelligence layer for an integrated ten-skill AI Portfolio Optimization system developed as part of the University of Tennessee's IE 591 course.

### Purpose

Integrate validated analytical outputs from Skills #1–#9 to support evidence-based investment decisions, multi-objective portfolio evaluation, scenario analysis, risk assessment, and explainable recommendations.

### Key Capabilities

- Multi-objective investment decision support
- Portfolio strategy comparison and ranking
- Goal-based optimization and constraint enforcement
- Scenario analysis and decision robustness testing
- Evidence-grounded AI explanations
- Deterministic execution without an OpenAI API key
- Multi-agent orchestration and analytical integration
- Interactive decision dashboards and reporting
- Decision governance, traceability, and auditability
- Independent academic validation

### Technology Architecture

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python
- **AI Integration:** Optional OpenAI API
- **Repository:** GitHub
- **Execution:** Standalone and integrated modes
